Pembaruan otomatis sekarang juga jalan di build TV/proyektor.

- APK TV (com.lokotube.app.tv) punya pemeriksa pembaruan sendiri: dialog
  "Pembaruan tersedia" muncul seperti di HP, mengunduh APK TV dari rilis
  GitHub, lalu menyerahkannya ke pemasang sistem.
- Tiap build hanya mengambil APK-nya sendiri: HP mengabaikan aset LokoTubeTV,
  TV hanya menerima aset LokoTubeTV. Tanpa pemisahan ini, build TV bisa
  memasang APK HP sebagai aplikasi kedua yang terpisah.
- Setiap rilis sekarang membawa dua aset, jadi pembaruan TV tidak lagi perlu
  disalin manual lewat adb.
- Kalau TV box tidak punya layar "izinkan pasang dari aplikasi ini", app
  membuka halaman detail aplikasi sebagai jalan terakhir.
